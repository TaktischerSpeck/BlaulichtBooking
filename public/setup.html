BlaulichtBooking · Erster Start

In wenigen Schritten startklar.

Datenbank verbinden und euren Zugang einrichten.

Lege zuerst in Plesk unter Datenbanken eine leere MariaDB-/MySQL-Datenbank mit Benutzer an. Setze unter Node.js → Umgebungsvariablen einen selbst gewählten SETUP_TOKEN mit mindestens 16 Zeichen und starte die App neu. Dieser Code schützt die einmalige Einrichtung.

1. Einrichtung freischalten


2. Datenbank verbinden


Bei einer Datenbank auf demselben Plesk-Server meist 127.0.0.1.
Die Datenbank muss bereits in Plesk existieren. Alle benötigten Tabellen werden automatisch angelegt. Eine vorhandene SQLite-Datei wird durch die Auswahl von MariaDB nicht übertragen.

3. Zugang festlegen


4. E-Mail-Versand (optional)

Für Bestätigungs- und Freigabelinks wird SMTP benötigt. Du kannst die Werte auch später in Plesk als Umgebungsvariablen setzen.


Datenbankzugang und automatisch erzeugter Anwendungsschlüssel werden im geschützten Datenverzeichnis außerhalb des öffentlichen Ordners gespeichert. PIN und Admin-Passwort werden ausschließlich als Hash in der Datenbank abgelegt.
